# Case Assignment: The "Risk Auditor" AI Agent

### **The Goal**
Build a prototype of a smart assistant that helps our risk officers understand and "talk" to complex risk management documents. You have **3 days** to deliver a working version.

### **Business Requirements**
*   **Expert-Level Understanding**: The agent shouldn't just "find" text. It needs to "understand" context. If a user asks, *"How shoud AI model risk be managed?"*, the agent should be able to reason across different parts of the document to give a logical answer.
*   **Conversational Memory**: The agent needs to remember what was said earlier. A user should be able to ask follow-up questions without repeating the whole context.
*   **A Professional User Interface**: Build a simple, clean web page where users can upload a document and start a conversation. 
*   **Reliability and Safety**: The agent must be honest. If the document doesn't contain an answer, the agent should say "I don't know" rather than making things up. It should also be "guarded" against users trying to trick it into ignoring company policy.
*   **Automated Quality Control**: You must set up a system that automatically checks your work. Every time you update the code, a "robot" (automation script) should run to ensure the AI's logic is still accurate and the app isn't broken.

### **Delivery & Presentation**
1.  **The Code**: Share your work via a GitHub link.
2.  **The "Why" Document**: In your README, explain your system design and design choices. 
    *   What are the key features in your system?
    *   What are the major components in your system? 
    *   Why did you choose this specific way (for example to handle memory)? 
    *   How did you ensure the system is fast? 
    *   How did you ensure the system is stable?
    *   What would you do differently if you had a month instead of three days?
3.  **The Meeting**: You will have **10-15 minutes** to demo the working app using your own computer and **20-30 minutes** to defend your architectural decisions.
